# Решения, которых нет в документах (одна строка — одно решение)

- Python 3.10.6 (стоит на ноутбуке) вместо 3.11 из 01 §3; синтаксис совместим.
- Цена заявки завода в демо-книге = базисная цена контракта «навал» 32,5 за последний день (у каждого завода два контракта — навал и мешки, цены разные; навал одинаков по смыслу у всех пяти): Toshkent Conch 490 000, Qarshi Conch 510 000, Shangfeng 500 000, Jizzakh Cement 470 000, Huaxin 530 000.
- Регионы: 12 областей + город Ташкент + Каракалпакстан = 14 кодов (`app/regions.py`); склад Toshkent Conch — Ташкентская область, не город.
- [modules] Календарь: торговые дни Пн–Пт (праздники не учтены). 08.11.2026 — воскресенье, поэтому от DEMO_NOW ближайшее окно — пн 09.11 11:30 («завтра»), а не 08.11 11:30, как в примере теста 03 §2 M7; тест переписан на понедельник 09.11.
- [modules] График: каждый календарный день без сделок — точка с null (не только месяцы-пустоты); есть `bucket=week` для полутора лет на телефоне. Коридор — P10/P50/P90 по сделкам (не по тоннам) за 90 дней до DATA_CUTOFF.
- [modules] Контрфакт АИ-92: объёмы 5/3/2/4/3 т — демо (в реестре 2–5 т), помечено в файле; P* = 13 357 005, переплата 69 234 сум. Одна цена считается мини-аукционом в market/counterfactual.py (правила 02 §4.4 без доставки) до появления публичной функции движка.
- Ответов калькулятора UZEX в данных нет: `data/demo/calc_samples.json` посчитан по составляющим ставки (0,13% + 0,05%, НДС 12%) на суммах реальных сделок; тест сверяет единую ставку 0,2016% с ними (±1 сум).
- 08.11.2026 — воскресенье: ближайшая корзина по календарю — пн 09.11 11:30; в демо корзину закрывают кнопкой «Закрыть корзину сейчас» (подписана как демо).
- [modules] Сделка (deal_id) = `{run_id}:{mandate_id}`; эндпоинты escrow/audit принимают и голый `mandate_id` (берётся последний прогон). Реестр прогонов — в памяти процесса, `app/audit/sources.py`.
- [modules] Объяснение: общий контрфакт корзины показывается, только если исполнено ≥ 3 покупателей — при двух из суммы вычитается чужой потолок (ст. 16). Заводы в карточке — только регион и доставка, без имени. «Предложение от Y» при отсутствии сделки — да, «спрос до X» — нет (это чужой потолок).
- [modules] Узбекские шаблоны — кириллица, как названия регионов в `app/regions.py`. Перефразирование моделью — только при `EXPLAIN_LLM=1` и не офлайн, с проверкой: множество чисел в каждом предложении не изменилось, иначе шаблон.
- [modules] Эскроу: из DISPUTED по `timeout` → TIMEOUT_RELEASED (спор не подтверждён в срок); из RELEASED/CANCELLED/TIMEOUT_RELEASED переходов нет. Повторная ЭТТН после выплаты — 200 с `ignored: true` и записью в лог; `ettn_rejected` после RELEASED — 409. ЭТТН чужой сделки — 404. Меньше 4 подписей — 422 без перехода. Граница 0,5% включена, считается дробями без float.
- [modules] Gate: если `funds_available` не передан — берётся `demo_balance` из ДЕМО-реестра. Физлицо (`person_2035`) реестр не проверяет (ID-карта, ДЕМО).
- [modules] Радар: рёбра — общий брокер (≥ 75% совместных сделок, ≥ 4), частая пара продавец–покупатель (≥ 5 сделок и ≥ 60% сделок покупателя), общий адрес склада; «чужой регион» — факт об узле, не ребро. Демо-корзины `RADAR-DEMO-1` (флаг: брокер 14 из 16 + частый продавец), `RADAR-DEMO-2` (общий адрес), `RADAR-DEMO-CLEAN` (без флагов). Реальные прогоны сопоставляются с графом по ИНН из `register_mandate`.
- [intake] Ответ `/intake/parse` = структура 02 §M1 + доп. ключи `lang`, `computed` (поля, вычисленные кодом: мешки→т, цена за мешок ×20, «950»→950 000; передавать в `validator.check(..., computed)`), `defaults` (поля, заполненные по умолчанию), `hints` (коды подсказок). `confidence_note` — код, не текст: `numbers_verified | numbers_verified_partial | llm_numbers_dropped | empty_input`.
- [intake] Коды в `missing_fields`: имена полей + `confirm:max_price_t` (потолок < 100 000 или «950» без единицы → ×1000). Коды `hints`: `grade_options` (М300 и т. п.), `grade_conflict`, `qty_conflict` («20… нет, 200»), `qty_integer` (пол тонны, 2 мешка), `qty_from_bags`, `price_per_bag`, `price_assumed_thousands`, `price_conflict`, `region_ambiguous`, `deadline_past`, `deadline_invalid`, `llm_numbers_dropped`.
- [intake] «На следующей неделе» → понедельник следующей недели (для 8.11.2026, воскресенье, — 2026-11-09); 02 «понедельник+7» и 03 «→ понедельник» читаются одинаково.
- [intake] Без срока → `deadline = сегодня + 7` (ближайшая корзина сегодня) с пометкой в `defaults`; без марки → 32.5 в `defaults`; без условий оплаты → `after_delivery` в `defaults`. В `missing_fields` попадают только обязательные (commodity, qty_t, region, max_price_t) и недопустимые (М300, прошедшая дата).
- [intake] «Голое» число ≥ 100 000 без единицы считается потолком цены; «до N»/«N-гача» с N ≤ 31 без валюты — срок, не цена. Пустая строка/эмодзи/только цифры → missing всё.
- [intake] LLM вызывается только если офлайн собрал < 4 из 6 полей; заполняет только пустые поля и никогда — поля с конфликтом/ошибкой. LLM только размечает (число как сказано, единица, день, месяц); мешки, ×20, даты считает код; месяц от LLM принимается, только если название месяца есть в тексте. Кэш LLM (`data/cache/intake/`) читается и при DEMO_OFFLINE=1 (01 §8: «только офлайн-парсер и кэш»), сеть — нет.
- [intake] LLM через REST (httpx), без SDK: Gemini `GEMINI_MODEL` (по умолч. gemini-2.5-flash), запасной `ANTHROPIC_MODEL` (по умолч. claude-sonnet-5-5); бюджет 8 с на оба (60% первому).
- [intake] `/intake/stt` при недоступности распознавания отвечает 200 с `{"transcript":"", "source":"none", "error":"stt_unavailable"|"empty_audio"}`, не 500. faster-whisper грузит модель только из локального кэша (`WHISPER_ALLOW_DOWNLOAD=1` разрешает скачивание).
- [intake] faster-whisper по умолчанию: CUDA есть → `medium`, `int8_float16`; нет → CPU, `small`, `int8`; `WHISPER_MODEL` переопределяет. Только локальный кэш; нет модели → `{"error":"stt_unavailable","reason":"whisper_model_missing"}`.
- [modules] Заменяет решение о контрфакте при ≥ 3 покупателях: в карточке корзины цемента числа переплаты нет вообще (потолок поручения ≠ ставка в сегодняшнем аукционе). Вместо него фраза «Сегодня каждый платил бы свою ставку и гнался за последней секундой. Здесь одна цена для всех: P* на складе». Числовой контрфакт — только `/market/counterfactual/ai92`, подпись `source_label_ru` «реестр UZEX 06.11.2026, объёмы демо».
- Маршрут «какой завод кому везёт»: сначала приоритет «цена → время» решает, кто сколько тонн получает; затем при тех же тоннах суммарная доставка минимизируется (min-cost flow, networkx). При равной доставке заводы по приоритету продавцов — правило Xetra «не больше одной частичной» сохраняется.
- [frontend] Мок фронта — записанные настоящие ответы бэкенда (TestClient, сид 2035) в `frontend/src/api/fixtures/http.json`; пользователь в моке занимает место покупателя b1. Мок включается сам, если бэкенд не отвечает или маршрута нет, — в футере плашка «мок-данные».
- [frontend] ИНН по умолчанию на входе — 900000001 из ДЕМО-реестра (иначе гейт блокирует «ИНН не найден»).
- [frontend] Числовой контрфакт показывается только на вкладке «АИ-92» экрана «Рынок»; в «Почему такая цена» — фраза `counterfactual` с бэкенда как есть.
- [frontend] Экран «Результат»: если поручение исполнено двумя заводами, доставка = цена с доставкой − цена торгов (средневзвешенная), заводы перечислены через «+».
