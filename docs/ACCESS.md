# Доступ по коду и лимиты (документ 11 §1, §2, §5)

## Уровни

| Уровень | Как получить | Что видно во фронте |
|---|---|---|
| guest | ничего; при первом запросе — подписанная cookie `intent_pid` (свой `principal_id`) | разбор фразы только офлайн (`source: offline`), микрофона нет, в «Ещё → Код доступа» поле кода и строка «разбор без нейросети; у жюри — с нейросетью и голосом» |
| jury | код с карточки в «Ещё → Код доступа» или ссылка `/?k=КОД` (код сразу убирается из адреса) → httpOnly-cookie `intent_access` на 24 ч | + разбор сложных фраз моделью, микрофон; в «Ещё» — «жюри: нейросеть и голос включены», остаток квоты, «выйти» |
| admin | `/more?admin=СЕКРЕТ` → секрет в sessionStorage вкладки, уходит заголовком `X-Admin-Token` | + «Закрыть корзину сейчас» и «Сбросить демо». Старый `?admin=1` ничего не даёт |

Источник правды — `GET /auth/me` (`level`, `voice`, `can_close_basket`, `protected`, `limits_left`). Фронт ничего не решает сам:
всё, что он прячет, бэкенд всё равно не выполнит (403 / офлайн).

«Мои поручения» под защитой — по cookie участника: бэкенд подставляет `principal_id` из cookie в каждое поручение,
`/mandate/mine` с чужим id отдаёт пустой список, `/mandate/{id}` чужого — 404.

Лимит (429) и запрет (403/401) приходят как `{"detail": {"code", "retry_after", "n", "message_ru", "message_uz"}}` +
заголовок `Retry-After`; фронт показывает строку по `code` (RU/UZ-латиница, `acc.err.*` в i18n) — в блоке ошибки экрана и
плашкой сверху на время ожидания.

## Включение

Защита включена при `ENV=prod` (всегда) или `AUTH_ENFORCE=1`. Без них локальный стенд работает как раньше
(все тесты master проходят без изменений).

```
python scripts/gen_codes.py --n 10 --html D:\Hackathon\UZEX\jury_cards.html
```

печатает `JURY_CODES=…`, `ADMIN_TOKEN=…`, `AUTH_SECRET=…` — эти три строки в `.env` сервера (рядом `ENV=prod`).
Файл карточек — вне репозитория. `AUTH_SECRET` одинаковый во всех воркерах, иначе cookie жюри «слетают» между ними.

Локальная проверка под защитой на своих портах (не мешая основному стенду):

```
cd backend && AUTH_ENFORCE=1 python -m uvicorn app.main:app --port 8010
cd frontend && VITE_BACKEND=http://127.0.0.1:8010 npm run dev -- --port 5190
```

Если второй стенд запускается из git worktree с общим `node_modules`, задайте `VITE_CACHE_DIR=<своя папка>`,
чтобы не трогать кэш зависимостей основного dev-сервера.

## Квота нейросети

30 вызовов в час на код, 300 в день на всех (`RL_LLM_CODE_HOUR`, `RL_LLM_DAY`). Считается каждый настоящий вызов
провайдера — и тот, чей ответ фильтр отбросил; исчерпана квота кода — разбор офлайн с подсказкой `llm_limit`, без 429.
Строгая проверка чисел (`qty_t` 1…10 000, `max_price_t` 10 000…100 000 000 → 422) работает только под защитой;
на открытом стенде сервис по-прежнему отвечает карточкой с ошибкой (tests/edge).
