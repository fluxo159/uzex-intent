# Проверка перед публикацией

Дата: 17 ноября 2026. Это проверка исходников и состава публикации, не сторонний пентест и не гарантия отсутствия всех уязвимостей.

## Общие проверки

- Gitleaks 8.30.1 с проверкой SHA-256 сканера: подготовленные файлы без находок секретов. Перед отправкой также сканируется вся новая Git-история.
- Проверены имена файлов и личные идентификаторы; рабочие .env, базы, cookies, журналы, локальные карточки и готовые старые приложения исключены.
- Git-автор использует GitHub noreply, а не личную почту.
- CI имеет только `contents: read`; Actions закреплены полными SHA, секреты сервера не используются.

## Intent

- Обновлены уязвимые Vite/Vitest/router и Python-зависимости; npm audit и pip-audit закреплённого runtime: известных уязвимостей не найдено.
- Backend: 783 теста пройдены; frontend: 49 тестов и production-сборка пройдены.
- Добавлен отказ при некорректном сроке подписанного токена.
- Dev-сервер и предпросмотр ограничены loopback; реальный домен заменён документационным примером.
- Исторические инструкции с IP/настройками реального сервера, QR и производные PDF/снимки слайдов исключены. Демо-скриншоты интерфейса сохранены.
- Проверены существующие границы ролей, cookie, лимиты запросов и объёма тела. Числовые расчёты отделены от LLM.

Локальный режим допускает незащищённое демо; не публикуйте его как production. Перед отдельным хостингом нужны `ENV=prod`, уникальные секреты, ограниченный CORS, HTTPS и проверка конкретного reverse proxy. Ввод голоса/текста с включёнными облачными моделями передаётся выбранному провайдеру. Эскроу, подпись и реестры демонстрационные, настоящие деньги не поддерживаются.

Проверка не включала проникновение на сервер или платные вызовы моделей. Обновление исходников на GitHub не обновляет ранее развёрнутый сервис.
