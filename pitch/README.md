## Показ HTML-версии

Открыть `index.html` в Chrome или Edge (двойной клик, сервер не нужен), нажать **F** для полного экрана.

- → / пробел / PageDown — следующий слайд; ← / PageUp — предыдущий; Home / End — первый/последний.
- Слайд масштабируется под любой экран без прокрутки внутри слайда.
- `index.html#p4` — открыть сразу на 4-й странице.
- На 9-й странице курсор мигает только в HTML; в PDF он виден постоянно.
- Движение (только HTML): при переходе на слайд элементы появляются — fade и сдвиг 8 px, 300 мс, шаг 60 мс. На стр. 4 пять сделок АИ-92 за 700 мс сереют и выстраиваются под одной ценой. Что появляется на каком слайде — карта `APPEAR` в `bind.js`.
- При `prefers-reduced-motion: reduce` или с `index.html?static` — сразу конечные состояния. PDF и `shots/` всегда статичны.

## Правила вёрстки

- Минимальный кегль — 28 px на 1920 (читаемость с 10 м); числа 96–200 px моно с табличными цифрами.
- Одна мысль на слайд, лайм — один акцент на странице, лаванда — только «модель 2035».
- Узбекские слова — латиницей (Niyat birjasi).

## Пересобрать PDF

Из папки `uzex-intent`:

```bash
python pitch/export.py --shots
```

Порядок работы: `data.js` из `docs/pitch_numbers.json` → `qr.png` → `pitch.pdf` через Playwright (chromium) → проверки:
9 страниц, < 15 МБ, шрифты встроены, **ни одного глифа системным шрифтом**, каждое `data-n` найдено в json (иначе — ошибка), ничего не вылезает за 1920×1080.

Если цифры в продукте поменялись — сначала `python scripts/export_pitch_numbers.py`, потом `python pitch/export.py`.

Если Playwright не установлен: `pip install playwright qrcode pypdf`, затем `python -m playwright install chromium`.

## Поменять адрес в QR

По умолчанию `https://demo.example/guest`. Пока сервер не поднят — адрес ноутбука:

```bash
python pitch/export.py --qr http://192.168.1.5:5181/guest
```

То же через переменную окружения `PITCH_QR_URL`, или поменять `QR_URL` в начале `export.py`. Пересобираются `qr.png`, подпись под QR и PDF.

QR — тёмные модули на лаймовой плитке: на чёрном слайде это лаймовый квадрат, а камеры телефонов читают привычную полярность (тёмное на светлом). Инвертированный код (лаймовые модули на чёрном) часть камер не распознаёт.

## Переснять скриншоты продукта (стр. 6)

Фронт `http://localhost:5178`, бэкенд `http://localhost:8000`. Порядок: `POST /demo/reset` с заголовком `X-Admin-Token` (значение — `ADMIN_TOKEN` из `.env`, в файлы и чат не выводить) → Playwright: `/more?admin=<секрет>`, дверь «Я предприниматель», ИНН `900000005` → `/market`, кнопка «Закрыть корзину сейчас», снимок 1920×1080 → `/plant` → телефон 390×844: `/buy`, фраза прораба, «Разобрать» → снова `POST /demo/reset`. Готовые PNG положить в `pitch/mvp/` под теми же именами.

## Шрифты

Geist и JetBrains Mono скачаны один раз с Google Fonts (подмножества cyrillic, cyrillic-ext, latin, latin-ext + стрелки → ↗ и минус −). Это переменные шрифты, поэтому Chromium встраивает их в PDF как Type3 — контуры глифов внутри файла, в любом просмотрщике выглядят одинаково.
