# Security

Не публикуйте токены, cookies, рабочие базы или персональные данные в Issues. Для конфиденциального сообщения об уязвимости используйте Private vulnerability reporting в разделе Security репозитория, если функция доступна.

Перед повторным развёртыванием проверяйте актуальность зависимостей, локальные настройки и [ограничения проверки](docs/SECURITY_REVIEW.md). Поддержка всех прежних выпусков не заявлена.
